## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Dual Player Mixing** — Mix audio from two digital players simultaneously for seamless transitions.
- **Sampler with 16 Slots** — Comes with a sample editor to create custom samples for your sessions.
- **Automatic Gain Control (AGC)** — Equalizes output sound to remove sharp differences, ideal for MP3 files.
- **Streaming Option** — Use BPM Studio as an Internet Radio Frontend Software for live mixing.
- **BPM-Remote Access** — Control the software remotely via Telnet or HTML commands.
